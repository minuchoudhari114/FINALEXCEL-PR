## 🌟 1. Project Overview

## 🧠 5. Excel Functions & Techniques

### ① Basic Mathematical Functions

Used for calculations and business summaries.

`SUM()` · `AVERAGE()` · `MIN()` · `MAX()` · `COUNT()`

**Example:**
```excel
=SUM(E2:E251)
```

### ② Logical Functions

Used to classify customers and evaluate conditions.

`IF()` · `AND()` · `OR()`

**Example:**
```excel
=IF(C2>=10000,"Premium","Regular")
```

### ③ Conditional Functions

Used to calculate values based on specific conditions.

`COUNTIF()` · `SUMIF()` · `COUNTIFS()` · `SUMIFS()`

**Example:**
```excel
=SUMIF(A2:A251,A2,E2:E251)
```

### ④ Lookup & Reference Functions

Used to retrieve matching customer and business information.

`VLOOKUP()` · `INDEX()` · `MATCH()`

**Example:**
```excel
=INDEX(B2:B251,MATCH(A2,A2:A251,0))
```

### ⑤ Text Functions

Used to extract and manipulate text values.

`LEFT()` · `RIGHT()` · `LEN()` · `CONCATENATE()`

**Example:**
```excel
=LEFT(B2,2)
```

### ⑥ Date & Time Functions

Used for date calculations and monthly analysis.

`TODAY()` · `NOW()` · `MONTH()` · `YEAR()` · `EOMONTH()`

**Example:**
```excel
=MONTH(A2)
```

### ⑦ Dynamic & Analytical Functions

Used for data extraction and advanced analysis.

`FILTER()` · `SLOPE()` · `INTERCEPT()` · `RSQ()`

**Example:**
```excel
=FILTER(A2:M251,A2:A251="ST025")
```
